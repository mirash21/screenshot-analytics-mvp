# 🚀 Быстрый старт

## Минимальные шаги для запуска системы

### 1. Подготовка (5 минут)

```powershell
# Перейдите в директорию проекта
cd "Система автоматического анализа скриншотов рабочих столов сотрудников"

# Создайте структуру папок
mkdir storage\screenshots, storage\database, incoming, config

# Сгенерируйте пароль и создайте .env файл
python setup.py
```

### 2. Настройка Google Sheets (опционально, 10 минут)

Следуйте инструкции в файле [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md):

1. Создайте Service Account в Google Cloud
2. Создайте Google Таблицу и поделитесь с Service Account
3. Скопируйте JSON ключ в `config/service_account.json`
4. Укажите ID таблицы в `.env`

### 3. Настройка пути к скриншотам (2 минуты)

Откройте `docker-compose.yml` и измените строку 13:

```yaml
volumes:
  - D:/Скрин:/app/incoming:ro  # <-- Укажите ваш путь
```

**Важно:** Структура должна быть: `Имя_Сотрудника/ГГГГММДД/ЧЧММСС.jpeg`

### 4. Запуск системы (3 минуты)

```powershell
# Вариант A: Использовать скрипт развертывания
.\deploy.ps1

# Вариант B: Вручную
docker-compose up -d
```

### 5. Доступ к дашборду

Откройте браузер: **http://localhost:8501**

- Логин: `admin`
- Пароль: тот, который вы указали в `setup.py`

## ✅ Проверка работы

### 1. Добавьте тестовые скриншоты

Создайте структуру:
```
D:/Скрин/Тест/20250603/090000.jpeg
```

### 2. Подождите 5 минут

Data collector сканирует папку каждые 5 минут.

### 3. Проверьте дашборд

- Откройте страницу "📊 Главная"
- Должны появиться статистика и графики

### 4. Проверьте Google Sheets (если настроено)

- Откройте вашу Google Таблицу
- Должны появиться записи с статусом "Работа" или "Личное"

## 🆘 Проблемы?

### Контейнеры не запускаются
```powershell
docker-compose logs
```

### Нет данных в дашборде
1. Проверьте логи data-collector:
   ```powershell
   docker-compose logs data-collector
   ```
2. Убедитесь что структура папок правильная
3. Подождите下一个 цикл сканирования (5 минут)

### OCR не работает
```powershell
docker-compose logs ocr-analyzer
```

### Google Sheets не отправляет данные
1. Проверьте логи: `docker-compose logs ocr-analyzer`
2. Убедитесь что Service Account имеет доступ к таблице
3. Проверьте что Google Sheets API включен
