# Changelog

Все изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [2.0.0] - 2024-01-15

### Добавлено
- ✅ **Улучшенное OCR распознавание** с OpenCV предобработкой
  - Адаптивная бинаризация для лучшего выделения текста
  - CLAHE (Contrast Limited Adaptive Histogram Equalization) для улучшения контраста
  - Median blur для подавления шума
  - Масштабирование 2x для мелкого текста
  - LSTM OCR engine для повышенной точности
  
- ✅ **Определение открытых приложений**
  - Классификация по типам приложений (Работа/Личное)
  - Словарь рабочих приложений: Excel, Word, 1C, Битрикс, Figma, VS Code, Jira, Slack, Teams, Zoom, SQL
  - Словарь личных приложений: YouTube, VK, Ozon, Wildberries, Кинопоиск, игры
  - Детализация обнаруженных приложений в отчетах
  
- ✅ **Интеграция с Google Sheets**
  - Автоматическая передача данных в реальном времени
  - Service Account аутентификация
  - Пакетная отправка для оптимизации
  - Формат: Дата | Время | Сотрудник | Статус | Детали
  - Инструкция: [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md)
  
- ✅ **Обновленная классификация**
  - Новые категории: 'work', 'user', 'unknown'
  - Приоритет определению приложений перед ключевыми словами
  - Уверенность классификации от 0.0 до 1.0

### Изменено
- Обновлены ключевые слова в словаре (work/user вместо productive/unproductive)
- Обновлены SQL запросы в дашборде для новых категорий
- Улучшена логика классификатора с приоритетом приложений

### Обновлено
- Docker Compose конфигурация для Google Service Account
- ENV конфигурация с новыми параметрами
- Документация README.md

### Технические детали
- Добавлена библиотека OpenCV (opencv-python-headless)
- Добавлены Google API библиотеки (google-auth, google-api-python-client)
- Улучшена обработка ошибок в OCR и Google Sheets интеграции

## [1.0.0] - 2026-06-03

### Добавлено
- ✅ Модуль сбора данных (data-collector)
  - Автоматическое сканирование папки со скриншотами
  - Парсинг метаданных из структуры папок (Имя/Дата/Время)
  - Копирование файлов в структурированное хранилище
  - Запись метаданных в SQLite БД
  - Удаление исходных файлов после обработки
  
- ✅ Модуль OCR анализа (ocr-analyzer)
  - Распознавание текста с помощью Tesseract OCR
  - Поддержка русского и английского языков
  - Предобработка изображений для улучшения качества
  - Классификация по ключевым словам (продуктивно/непродуктивно)
  - Сохранение результатов в БД
  
- ✅ Дашборд администратора (Streamlit)
  - Авторизация с хешированием паролей
  - Главная страница с общей статистикой
  - График продуктивности по дням
  - Рейтинг сотрудников
  - Профиль сотрудника с лентой скриншотов
  - Лента нарушений (только непродуктивные)
  - Управление словарем ключевых слов
  
- ✅ База данных SQLite
  - Таблицы: employees, screenshots, analysis_results, keywords
  - Индексы для оптимизации запросов
  - Внешние ключи и целостность данных
  
- ✅ Docker контейнеризация
  - docker-compose.yml для оркестрации
  - Отдельные контейнеры для каждого модуля
  - Общие volumes для данных
  - Настройка ресурсов для OCR
  
- ✅ Скрипты утилит
  - rotation.py для автоматической очистки старых данных
  - setup.py для быстрой настройки
  - deploy.ps1 для развертывания на Windows
  
- ✅ Документация
  - README.md с полной инструкцией
  - QUICKSTART.md для быстрого старта
  - .env.example с примером конфигурации

### Технические детали
- Python 3.11
- Tesseract OCR 5.x с русским языковым пакетом
- Streamlit 1.30.0
- Pillow 10.1.0
- pytesseract 0.3.10
- Plotly 5.18.0 для визуализации
- SQLite для хранения данных

### Архитектура
- Модульная архитектура с разделением ответственности
- Контейнеризация для простоты развертывания
- SQLite как легковесное решение для MVP (25 сотрудников)
- Keyword-based классификация для простоты настройки

### Безопасность
- Хеширование паролей с солью (SHA256)
- Ограничение доступа к дашборду
- Локальное хранение всех данных
- Read-only монтирование входящих файлов

### Производительность
- Обработка батчами по 10 скриншотов
- Интервал сканирования: 5 минут
- Интервал анализа: 60 секунд
- Ротация данных: 30 дней
- Ожидаемая нагрузка: ~1200 скриншотов/день
